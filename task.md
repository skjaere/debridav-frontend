# DebriDAV frontend
We are going to make a frontend for administering debridav ( /home/william/IdeaProjects/debridav )
This frontend should be able to view and change configuration properties defined in debridavs application.properties. The configuration properties should be grouped together in logical sections with their own menu items.

The frontend should use TypeScript, react and express and use the dracula color theme. It should have a bold, stylish and modern look. It should be mobile friendly, and look like a "dashboard". It must have a login page for authentication.
The menu should have a main configuration section, which each subsection being it's own menu item.
Make sure to use your frontend-development skill, and playwright mcp during development. If you need to debug debridav make sure to use the jdwp mcp. The code related to updating configuration and authentication in debridav is uncommited, so you can easily find it.
